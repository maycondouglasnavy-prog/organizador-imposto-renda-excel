# Desafio de Projeto: Organizador de Dados para Imposto de Renda no Excel

Repositório criado para a entrega do desafio de projeto da **DIO (Digital Innovation One)**, focado na criação de uma ferramenta robusta e amigável em Excel para centralizar, validar e organizar informações essenciais para a declaração de imposto de renda.

## 🎯 Objetivo do Projeto
Desenvolver um agregador de dados automatizado no Excel que permita ao usuário controlar suas entradas financeiras e cadastrais de forma eficiente, utilizando menus de navegação intuitivos, validações automáticas de dados e recursos visuais voltados à melhor experiência de uso.

---

## 🛠️ Funcionalidades e Estrutura da Ferramenta

A planilha foi estruturada em abas funcionais para separar o fluxo de controle:
1. **TITULAR / Dados Principais**: Cadastro e consolidação das informações cadastrais e gerais do contribuinte.
2. **INFORMES**: Centralização dos dados extraídos de informes de rendimento e fontes pagadoras.
3. **NOTAS**: Anotações, lembretes e links rápidos de acesso úteis para o período de declaração.
4. **TABELAS DE APOIO**: Bases auxiliares utilizadas para alimentar menus suspensos e validações de dados automáticas.

---

## 🚀 Tecnologias e Recursos Utilizados
- **Microsoft Excel**: Construção de tabelas estruturadas, formatação condicional e design limpo.
- **Validação de Dados**: Criação de menus suspensos para padronizar e mitigar erros de preenchimento.
- **Links Rápidos e Navegação**: Facilidade de transição entre as seções da planilha com cara de aplicativo.
- **GitHub**: Versionamento e documentação técnica do projeto.
